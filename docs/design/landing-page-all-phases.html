For your IT team

Installed with one command.

  • Docker Compose: on-premise, VPS, or private cloud.
  • From 4 vCPU, 16 GB RAM, 50 GB disk. GPU recommended.
  • Local models via Ollama or vLLM. All open source.
# 1. get the code
git clone https://github.com/<user>/nawa-ai && cd nawa-ai
# 2. configure
cp .env.example .env
# 3. start with a local LLM
docker compose --profile local-llm up -d

FAQ

Common questions.

Is this a subscription service (SaaS)?

No. You install and run it yourself.

Is our data sent to an AI provider?

Not by default. External providers need admin approval and are off in offline mode.

What if the answer is not in our documents?

It says it found nothing. It does not guess.

Can the AI change or delete our data?

No. Data access is read-only. Risky actions need approval.

How accurate is it?

Measured on a standard question set, failures published. Your own accuracy is set in the pilot.
